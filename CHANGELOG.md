# Changelog

Releases from 6.0.0 on are generated by release-please from Conventional Commits.

The tags `4.0.0`, `5.0.0` and `5.0.1` (2024) belong to an earlier implementation that stored section IDs and cached each listed parameter as its own page. Versions `1.0.0` to `1.1.2` (2025) introduced the current implementation; 6.0.0 continues that line and is numbered above 5.0.1 so Composer and Packagist treat it as the latest.
