# Craft Blitz



## Requirements

This plugin requires Craft CMS 4.5.0 or later, and PHP 8.2.0 or later.

## Installation

Add the repository to the **composer.json** file and run `composer update`.   

``` json
"require": {
	"lameco/craft-blitz": "dev-main"
},
"repositories": [
    {
      "type": "vcs",
      "url": "git@bitbucket.org:Lameco/craft-blitz.git"
    }
]
```
